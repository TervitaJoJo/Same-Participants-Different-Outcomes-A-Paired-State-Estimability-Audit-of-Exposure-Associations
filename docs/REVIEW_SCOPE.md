# Anonymous review scope

The primary reviewable material is the paired-state estimability audit and its simulation implementation. Historical source folders are retained only where needed to show the analysis dependency chain. The code package does not make a claim about prospective registration or causal identification.

Required empirical survey files are intentionally absent. Reviewers can inspect the estimator and run the simulation validator without access to restricted datasets. Any external aggregate-result figure rendering requires aggregate CSVs supplied separately by the authors after data-use review.

Neutral folder names preserve relative imports while avoiding private project names. The original-to-anonymous mapping is retained privately outside this archive and must not be published with the blinded submission.
